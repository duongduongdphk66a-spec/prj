# Impeccable Design Skill

This skill provides out-of-distribution design craft for frontend applications, ensuring award-winning aesthetic quality, zero AI slop, strict contrast compliance, and authentic human touch.

## Core Commands:
- `/impeccable init`: Initialize design contracts (`PRODUCT.md` and `DESIGN.md`).
- `/impeccable audit`: Perform automated and visual defect detection across UI components.
- `/impeccable critique`: High-level UX, visual hierarchy, and cognitive load assessment.
- `/impeccable polish`: Fine-tune micro-spacing, typography, borders, shadows, and browser surfaces before shipping.
- `/impeccable distill`: Strip unnecessary visual clutter and reduce container nesting.
- `/impeccable harden`: Add comprehensive error states, empty states, edge case handling, and accessible focus management.
- `/impeccable bolder`: Elevate contrast, hierarchy, and personality for key surfaces.
- `/impeccable quieter`: Soften aggressive elements for refined, understated elegance.
- `/impeccable animate`: Author deliberate, purposeful motion curves with exponential ease-out.
- `/impeccable delight`: Add tactile physical response, delightful hover moments, and spring dynamics.

## Craft Floor Guidelines:
1. **The Brief Wins**: Honor pinned aesthetics and brand lane without imposing generic tropes.
2. **No Eyebrow Clichés**: Headings carry their own weight; remove decorative micro-labels above titles.
3. **No Card Soup**: Avoid nesting cards inside cards; utilize negative space and subtle dividers instead.
4. **Theme Browser Surfaces**: Always theme `::selection`, `caret-color`, `custom scrollbars`, `:focus-visible`, and `font-variant-numeric: tabular-nums`.
5. **Tinted Shadows**: Ensure shadows have vertical offsets and soft blurs; never use 0-offset colored halos.
